# Confirmed fixes from the 5 November 2026 review

This is a limited list of changes made and rechecked in the current review. It replaces earlier broad “all P0/P1 resolved” claims. Full scope and limits are in [`ACCEPTANCE_MATRIX.md`](ACCEPTANCE_MATRIX.md).

- Corrected Section 60 FAQ wording and removed any suggestion that contacting a hotline extends the filing period.
- Removed an unsupported statement that supporting evidence is mandatory; the interface now recommends keeping relevant records and directs users to DNCRP to confirm filing requirements.
- Made browser-local, unencrypted storage disclosures explicit.
- Removed an unsupported “secure external AI provider” statement and clarified consented material transfer.
- Removed numeric confidence percentages from fictional fixture data and deterministic fallback output.
- Added names to document search/type controls; strengthened intake and quick-search modal semantics, keyboard behavior, and focus restoration.
- Corrected the 16699 card to state toll-free only, without unverified service hours or historical 16430 status.
- Fixed measured mobile masthead overflow at 125% text scaling.

These changes do not establish legal certification, encrypted storage, account isolation, official filing, or WCAG conformance.
